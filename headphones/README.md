**Headphones Landing Page**


A fully responsive landing page for a headphones company, built from scratch using HTML and CSS without any frameworks or libraries.


📋**Project Overview**

This project implements a complete landing page based on a designer file, featuring:

Responsive design that adapts to desktop, tablet, and mobile screens
Custom CSS styling with no external libraries
Accessibility-focused markup
Interactive hover effects

🎨 **Design Specifications**

Breakpoints

Desktop: > 480px
Mobile: ≤ 480px

**Color Palette**

Primary accent: #FF6565
Background (hero/results): Dark blue/navy
Background (main): White

Interactive Elements

Links hover/active: #FF6565
Button hover/active: opacity: 0.9

Layout

Max content width: 1000px (centered)

🚀 **Features**

 Header/Hero section
 "What we do..." section
 "Our results" section
 Contact form
 Footer

🛠️ **Technologies Used**

HTML5
CSS3
Responsive design principles
Semantic markup for accessibility

📱 Responsive Design
The layout automatically switches to mobile view when the screen width is 480px or less, ensuring optimal viewing experience across all devices.

🎯 **Project Goals**

Create a pixel-perfect implementation of the design
Ensure full responsiveness across all screen sizes
Maintain accessibility standards
Implement smooth hover/active states for interactive elements
